 RAG-Based AI Chatbot for Java Previous Year Question Papers

 Project Overview

The RAG-Based AI Chatbot for Java Previous Year Question Papers is an AI-powered chatbot designed to help students prepare for Java examinations.

The chatbot uses Retrieval-Augmented Generation (RAG) technology to retrieve relevant information from previous year Java question papers and provide accurate, meaningful, and easy-to-understand answers to students’ queries.

Instead of manually searching through multiple question papers, students can simply ask questions and get relevant answers instantly.

 Objectives

* To provide quick answers to Java-related questions.
* To make previous year question papers easily accessible.
* To reduce students’ time and effort during exam preparation.
* To use AI and RAG technology for intelligent question answering.
* To improve students’ understanding of important Java topics.

 Technologies Used

* Python – Backend programming.
* Streamlit – User interface.
* RAG (Retrieval-Augmented Generation) – Information retrieval and answer generation.
* Large Language Model (LLM) – Generates answers to user queries.
* Vector Database – Stores and retrieves relevant document information.
* PDF Processing – Extracts questions and information from PDF files.
* LangChain – Helps manage document retrieval and LLM integration.

 How It Works

1. Upload PDF: Previous year Java question papers are uploaded to the system.
2. Text Extraction: The system extracts text from PDF documents.
3. Text Chunking: Extracted text is divided into smaller sections.
4. Embedding Generation: Text chunks are converted into numerical vectors.
5. Vector Storage: Embeddings are stored in a vector database.
6. User Query: Students enter their Java-related questions.
7. Information Retrieval: The system searches for relevant information.
8. Answer Generation: The AI generates answers using the retrieved information.

 Installation and Setup

Step 1: Clone the Repository

git clone <repository-url>

Step 2: Open the Project Folder

cd RAG-Java-Chatbot

Step 3: Install Required Libraries

pip install -r requirements.txt

Step 4: Run the Application

streamlit run app.py

Step 5: Start Asking Questions

Open the application in your browser and enter Java-related questions to get answers from previous year question papers.
